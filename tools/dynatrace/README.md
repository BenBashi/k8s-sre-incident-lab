# היכרות עם Dynatrace

המטרה: להכיר את המסכים של Dynatrace, שמופיע בדרישות המשרה כחובה יחד עם Splunk.

## פעם אחת

- הרשמה: לפתוח ניסיון חינמי באתר של Dynatrace.
- התקנה: בתוך Dynatrace, לחפש Kubernetes ולבחור בהתקנה המודרכת. היא מייצרת פקודות להתקנת Dynatrace Operator ו־DynaKube עם טוקנים מוכנים.
- הערה: על kind ההתקנה המלאה לא תמיד עובדת. אם ה־OneAgent לא עולה, מסתפקים במסכים עם נתוני הדוגמה שבניסיון, כי המטרה היא להכיר את הממשק.

## המסכים שחייבים להכיר

- בעיות (Problems): ‏Davis, מנוע ה־AI של Dynatrace, מקבץ התראות קשורות לבעיה אחת ומציע root cause. בתקלה מתחילים מכאן.
- מפת התלויות (Smartscape): מי קורא למי: שירות, תהליך, host, ‏DB.
- שירותים (Services): זמן תגובה, שיעור כשלים ותפוקה לכל שירות ולכל endpoint.
- עקבות (Distributed traces): בקשה אחת לאורך כל השירותים, וכמה זמן לקח כל שלב. כאן רואים קריאה איטית ל־DB.
- לוגים (Logs): חיפוש לוגים, בדומה ל־Splunk.
- קוברנטיס (Kubernetes app): פודים, ‏workloads ואירועים.

## משפט לראיון

"ב־Dynatrace הייתי מתחיל מה־Problem card, שמראה את שרשרת ההשפעה, ואז מאמת את ההשערה ב־trace וב־Splunk."
